INSTALLATION — DO NOT CHANGE THE LIVE HOMEPAGE
1. Open the duplicated Home – Redesign page under Not Linked. Keep it password-protected while testing.
2. Click Edit. Add a BLANK SECTION at the top; remove its unnecessary blocks.
3. Click Add Block > Code, and stretch the block to the full width of the section.
4. Edit the Code Block, set Mode = HTML and Display Source = OFF.
5. Open sunshine_squarespace_homepage.html in a plain text editor; copy ALL the contents and paste them into the Code Block.
6. Click outside the block, Save, then test the password-protected redesign page in a normal browser preview. Some JavaScript previews are suppressed while logged in; check a real page load.
7. Once the new layout is displaying and scrolling properly, remove the ORIGINAL copied content sections beneath the custom code block from Home – Redesign ONLY.
8. Keep the existing main website Home page untouched until launch.

PLAN REQUIREMENT
HTML and CSS work in Squarespace Code Blocks. JavaScript for the mobile menu, slider and reveal effects requires Core, Plus, Advanced or another eligible plan, per Squarespace support.
